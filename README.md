# Machine Learning Assignment

This repository contains solutions for multiple machine learning tasks.

## Datasets

Some datasets are loaded using built-in libraries (e.g., Keras for Fashion-MNIST). Others may require manual download from sources such as Kaggle or UCI, as described in the notebooks.

## Tasks

- Q1: Regression
- Q2: Classification (Imbalanced Data)
- Q3: Dimensionality Reduction (PCA, t-SNE)
- Q4: Clustering (K-Means, Agglomerative, DBSCAN)
- Q5: Neural Networks (MLP vs CNN)

## Structure

- notebooks/
- report/
- requirements.txt

## Reproducibility

Each notebook can be run independently. Random seeds are fixed where applicable.
